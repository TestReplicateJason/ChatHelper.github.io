# Telegram Message Constructor

**Telegram Message Constructor** — это веб-инструмент, позволяющий создавать фейковые Telegram-сообщения с реалистичным интерфейсом. Он точно воспроизводит стиль официального Telegram-клиента, включая:

- 💡 Сообщения от пользователей и ботов
- 🖼 Аватарки, ники, дату и время
- 🔁 Пересланные сообщения и реплаи (в планах)
- 🎨 Реалистичное форматирование

## 🔧 Использование

1. Перейдите на сайт:  
   👉 [https://testreplicatejason.github.io/ChatHelper.github.io](https://testreplicatejason.github.io/ChatHelper.github.io)
2. Создайте сообщения, измените параметры (имя, текст, дата и т.д.)
3. Делаете экспорт результата

> Это отличный инструмент для дизайнеров, мемов, документации и просто фана.

---

## 🧠 Возможности (планируется)

- Экспорт результата в **HTML**
- Поддержка **реакций**, **подстраивающиеся блок сооббщения**
- Настройка темы как в Telegram
